# 國小國語文「學習共同體」公開授課教案與教學組件產生器

本 Skill 專為台灣國小教師設計，旨在依據**108 課綱精神**與**佐藤學教授「學習共同體（Learning Community）」理念**，協助教師完成深度的課前備課，產出具備「學生學習主體性」、「起點行為與迷思概念診斷」、「高階文本推論提問」的完整公開授課教學組件。

---

## 🎯 核心教學哲理與提問原則

### 一、學習共同體課堂三原則
1. **學生為學習主體**：拒絕教師主導的罐頭式劇本演出與數分鐘機械任務切碎；珍視學生的每一個起點提問，將其轉化為下一段探究的起點。
2. **起點行為與迷思診斷**：備課的核心在於精準掌握該年段學童的起點能力與底層迷思，在最適切的時機進行「敏察、串聯與拋回（Connecting & Retossing）」。
3. **高年級收編價值**：深入探究文本被選入該年段的獨特價值（如：從個人好的行為延伸至全球議題與組織號召、心智思辨躍遷）。

### 二、拒絕低階與脫離文本，堅持【扣緊文本‧高階推論】
* ❌ **拒絕直接提取**：不設計「單一行字就能查到答案」的低階問題。
* ❌ **拒絕天馬行空**：不設計「脫離課本憑空想像/主觀聊天」的問題。
* 🎯 **堅持黃金推論**：回答時必須說出「我是從第 O 頁第 O 行看出來的……」，涵蓋四大高階路徑：
  1. **【反差與矛盾】**：探究表象行為與內心情緒的落差（如：收到感謝信卻沒有笑容）。
  2. **【說服與動機】**：解碼文字背後的說服心理戰術（如：信件是索取還是夥伴邀請）。
  3. **【弦外之音與意圖】**：解析象徵修辭與作者隱含意圖（如：莎士比亞小斧頭與橡樹）。
  4. **【細節與前後對照】**：對照距離遙遠的兩處文字細節，推論心智成長脈絡。

## 🛠️ 自動產出五大教學組件

執行本 Skill 時，將會自動建立 `output/` 資料夾並生成以下 5 個教學組件：

1. **新北市官方格式教案與觀課紀錄表 (.docx)**：
   * 包含基本資料、設計理念、核心素養、領綱指標、學習目標、教材組織與學生迷思分析、3階段探究波浪流程表、觀課紀錄與觀課者收穫。
2. **新北市官方格式教案與觀課紀錄表 (.md)**
3. **學生高階探究學習單 (.docx & .md)**：
   * 4人小組共學專用，包含共學約定、基礎行動脈絡、四大高階推論欄位（含頁行證據）與生命實踐提案。
4. **教師導引版學習單 (.docx)**：
   * 供備課與巡走指導參考，包含文字定位、參考解答、常見迷思與教師引導話術。
5. **16:9 互動式 HTML 教師教學簡報 (.html)**：
   * 適用於觸控大螢幕與電子白板，支援鍵盤翻頁（`←` `→`）、全螢幕、簡報頁碼、以及每個跳躍課題旁的「點擊展開教師解答與導引」互動按鈕。

## 🚀 工作流程（Workflow）

1. **課文與年級確認**：
   * 詢問或擷取使用者提供的國語課文名稱、版本與年級。
2. **深度備課分析**：
   * 剖析文本結構、該年段收編價值、學生起點行為與三大核心迷思（Misconceptions）。
3. **高階提問設計**：
   * 依據四大推論路徑，設計 3~4 個「扣緊文本、無法直接抄到答案」的跳躍課題。
4. **自動生成文件與簡報**：
   * 執行 Python 腳本，生成 `.docx` (Google Docs 相容)、`.md` 與 `.html` 檔案至 `output/`。
5. **Git 與 GitHub 自動備份與發布**：
   * 自動執行 `git init`、建置 `.gitignore` 與 `README.md`，並透過 `gh repo create` 發布至 GitHub！
