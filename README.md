## 🎯 設計核心亮點

1. **教案理念**：
   * 一堂真正美麗的課堂，絕非照腳本演出的劇本，更非切碎為數分鐘的機械任務。
   * 珍視學生的每一個起點提問，將其轉化為下一段探究的起點。
2. **高階提問四大路徑**：
   * **反差與矛盾**：收到感謝信為何「沒有笑容」？
   * **說服與動機**：寫給比爾蓋茲的信是乞討還是「夥伴邀請」？
   * **弦外之音與意圖**：莎士比亞名言「小斧頭與橡樹」的雙層象徵。
   * **細節與前後對照**：雪球影響力如何從個人點心費擴大至全球。
