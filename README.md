## 🛠️ Skill 安裝與使用方式

本專案包含 Agent Skill 定義檔：`skills/slc-mandarin-lesson-design/SKILL.md`

### 安裝至 Antigravity / Claude Code / Codex：
將 `skills/slc-mandarin-lesson-design/` 複製到您的技能資料夾：
* **全域安裝**：`~/.gemini/config/skills/slc-mandarin-lesson-design/`
* **專案安裝**：`<你的專案>/.agents/skills/slc-mandarin-lesson-design/`
